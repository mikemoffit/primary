# The Pilgrimage — static landing page

A self-contained static site (no build step, no WordPress). Upload the contents of
`pilgrimage-landing.zip` to any web host: cPanel File Manager (extract into `public_html`),
Netlify Drop, Cloudflare Pages, Vercel, or GitHub Pages.

Files: `index.html`, `styles.css`, `favicon.svg`, `.htaccess` (Apache only, harmless elsewhere).

**Before going live:** open `index.html` and replace everything in `[square brackets]`
(dates, location, description, schedule, pricing, FAQ answers, Instagram link). The Register
button currently opens an email to registration@the-pilgrimage.com; swap its `href` for a
ticketing link if you have one.
